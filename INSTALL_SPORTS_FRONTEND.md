# Install Ahibi Sports Frontend

## Quick Installation

Run this command in the `client` directory:

```bash
npm install react-hot-toast
```

## Update Layout for Toast Notifications

Add the Toaster component to your root layout if not already present.

The auth page and dashboard are ready to use once the dependency is installed.

## Access Points

- Arena Partner Auth: http://localhost:3000/arena-partner/auth
- Arena Partner Dashboard: http://localhost:3000/arena-partner/dashboard

## Backend Must Be Running

Ensure the backend server is running on http://localhost:5000
